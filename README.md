# 👻 Quality of Life for Phasmophobia

Welcome! This project collects **newly created maps and utilities** that add quality-of-life features to *Phasmophobia* that the game doesn't currently have.

These tools are meant to **supplement your gameplay, not replace it**. They **do not reveal the ghost**. Finding and identifying it is still up to you and your team.

\---

## 📦 What's Inside

|Folder|Description|
|-|-|
|**New Phasmo Maps**|Newly created maps for Phasmophobia locations|
|**QOL Utilities**|Utilities that add quality-of-life features, including **PhasmoSanityHunt**|

\---

## ⚙️ Requirements

* Windows PC with *Phasmophobia* installed
* **.NET 8** runtime ([download from Microsoft](https://dotnet.microsoft.com/download/dotnet/8.0))

\---

## 🚀 Getting Started

1. Click the green **Code** button at the top of this page, then **Download ZIP**.
2. Extract the ZIP to a folder on your computer.
3. Make sure the **.NET 8** runtime is installed.
4. Open the folder for the map or utility you want and follow any instructions included there.
